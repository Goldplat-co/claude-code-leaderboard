# Claude Code 팀 사용량 리더보드

> GoldPlat 팀원들의 Claude Code 사용량을 시각화하는 대시보드.
> 누가 얼마나 활발하게 AI와 협업하고 있는지 확인할 수 있다.

## 기술 스택

| 레이어 | 기술 |
|--------|------|
| 프레임워크 | Next.js (App Router) |
| 배포 | Vercel |
| 데이터 | GitHub API + 스냅샷 |

## 주요 기능

- 팀원별 Claude Code 사용량 순위
- 기간별 트렌드
- 개인 프로필 페이지
- Best Practices 가이드

## 개발 환경

```bash
npm install
npm run dev
# http://localhost:3000
```
